# servicelog-legal

Privacy policy and terms of use of the Jobwise app, in English, Spanish, Portuguese and
French, published with GitHub Pages at https://ronyjdsl.github.io/servicelog-legal/

- Privacy policy: `/privacy/<en|es|pt|fr>/`
- Terms of use: `/terms/<en|es|pt|fr>/`

These pages are generated from the Markdown sources in the app repository
(`legal/*.md`, built with `scripts/build-legal-site.ts`). Don't edit the HTML by hand:
change the sources and rebuild.
